Tasks (quests)

Any option can start a task. Tick Starts Task on the option and fill in the fields:

Field Example Meaning
Task Tag Quest.FindKey Added when the task starts. Means "running".
Done Tag Quest.FindKey.Done Means "complete".
Complete On Tags Item.Key.Picked The task completes when all of these have been sent or added, in any order. The plugin then adds and sends the Done Tag. Leave it empty to add the Done Tag yourself.
Ask → line Played when the player talks again while the task is running ("Found it yet?").
Reward → line Played once, the first talk after completion ("You found it! Take this.").
Done → line Played if the player picks the option again after the reward ("I already gave you one.").

On the Option node, the Ask, Reward and Done pins are wired like any other output.

What the NPC does on each talk:

task not started        → Start
task running            → Ask
task complete           → Reward (once)
after reward            → Start; picking the task option again → Done
  • Already done before accepting. If the player picks the task option when its Complete On Tags already happened (they found the key first), the NPC goes straight to the Reward.
  • Canceling a task. If you remove the Task Tag, the task is canceled and the NPC starts from the beginning again.
  • Progress in Blueprint. Call Get Task Progress on the Tag Subsystem (e.g. "1 / 2" for a quest log) and Get Dialogue State on the component.
