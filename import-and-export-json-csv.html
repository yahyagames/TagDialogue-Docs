Import and export (JSON, CSV)

Right-click a Dialogue asset in the Content Browser:

Command What it does
Export Dialogue (JSON) / Import Dialogue (JSON) The whole dialogue: lines, options, actions, tasks and node positions.
Export Texts (CSV) / Import Texts (CSV) Only Id, Kind, Speaker, Text, Subtitle, for writers and translators. Importing updates texts by Id and keeps the graph, pills and comments.
Reimport Re-reads the .json the asset came from.

Creating assets from JSON

  • Drag one or many .json files into the Content Browser. Each becomes a Dialogue asset named after its file.
  • Tags the project doesn't have yet are added automatically to Project Settings → Gameplay Tags.
  • Files without node positions (hand-written or AI-written) are arranged automatically. Exported files keep their layout.
  • Problems such as broken links or unknown action types are reported in one message after import.

To write dialogues with AI, give the AI Writing Guide to any AI chat. It contains everything the AI needs: it asks you a few questions, then writes ready-to-import JSON. It's also the full reference for the JSON format.
