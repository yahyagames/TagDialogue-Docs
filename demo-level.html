Demo level

Tools → Tag Dialogue → Open Demo Level (or Open Demo on the first-run popup) opens a small village. It shows:

  • Blacksmith: a task with Ask / Reward / Done, a Once Only welcome and a random Pick for the reminder.
  • Guard: a Condition, a locked option (needs the sword), a Once Only warning and {Gold}.
  • Villagers: random barks that change after the quest.
  • Radio: the Subtitle style with an In Order Pick.
  • Key and gate: TDS Tag State components.

The demo dialogues' JSON files are in the plugin's Docs/Demo folder.
