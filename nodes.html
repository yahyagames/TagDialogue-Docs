Nodes

Start

Where the conversation begins on a fresh talk. When a task is running, the NPC may start somewhere else instead (see Tasks).

Line

Something a speaker says.

Field What it does
Speaker Who says it. Empty = the asset's Default Speaker.
Portrait Image for the UI. Empty = the Default Portrait.
Text The line. Supports text variables like {PlayerName}.
Audio Voice clip. It plays on the NPC and stops when the next line starts.
Once Only Play this line the first time only. Later talks skip it and go straight on; actions on its wire still run. Remembered per NPC and saved. Ignored on lines with options.
On Enter Actions Actions that run the moment the line starts (e.g. open a door while the NPC speaks).

A line either continues (one wire out) or asks (has options).

Option

What the player says. (Lines are what the NPC says.) Click Add option on a line, or right-click → Add Option and wire the line into it.

Field What it does
Text The player's words, short ("I need a sword.").
Subtitle Shown on hover: the full sentence or a hint ("I need a blade strong enough for the road.").
Required Tags The option is locked unless all these tags are in the tag state.
Hide When Locked Hide a locked option instead of graying it out.
After Closed What a closed option looks like: Gray Out or Hide (see Close Task).
Instant Picking it doesn't show the player's line; the reply plays right away.
Actions Run when the option is picked.
Starts Task Picking it starts a task (see Tasks).

Condition

Shows nothing. It checks the tag state and goes True or Else.

  • Set Condition with the standard Gameplay Tag Query editor: All / Any / No Tags Match, and nested expressions.
  • An empty condition is always true.
  • Example: If Quest.Key.Done → "Thanks again!" / Else → "Have you seen my key?"

Pick

Shows nothing. Each time the conversation passes through, it takes one of its outputs. Use + / − on the node to add or remove outputs.

Pick Mode Behavior
Random A random output, never the same one twice in a row.
In Order, Loop 1, 2, 3, 1, 2, 3…
In Order, Stay On Last 1, 2, 3, 3, 3… (great for "first time / second time / every time after")

Progress is remembered per NPC and saved.

End

Ends the conversation.
