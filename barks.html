Barks

Barks are lines an NPC says on its own: "Nice weather." or "Hey, watch it!". No UI takes over and no input is locked.

  1. Create a normal Dialogue asset for the barks. Usually it's a Pick (Random) node into a few lines, optionally behind a Condition.
  2. On the TDS Dialogue component, set Barks to that asset.

  3. Call Bark (e.g. on overlap, on a timer, when hit).

    • Bark Override plays a different asset this time, e.g. a "hurt" set.
    • Ignore Cooldown skips the cooldown.
    • It returns false if the NPC is in a conversation, on cooldown, already barking, or has nothing to say.

A bark plays from its start line through conditions, picks and Next wires. Each line stays up for its voice length, or for a time based on its text length (at least Bark Min Time).

Showing barks. Use any mix of these:

Way How
Subtitles (default) Project Settings → Tag Dialogue UI → Show Bark Subtitles is on by default. Nearby barks show as subtitles at the bottom of the screen. Set Bark Subtitle Widget to use your own (the templates create WBP_TDS_CinematicBark).
Above the head Add a TDS Bark Widget component to the NPC. It shows a speech bubble; Widget Class empty = a simple dark bubble. Your own widget just needs a TDS Bark Text or TDS Bark Subtitle inside. Max Distance hides far barks.
Your own Bind On Bark on the component (one NPC) or on the Tag Subsystem (every NPC).

Speaker colors (Project Settings → Tag Dialogue UI → Speaker Colors) color names in bark subtitles and dialogue text.
