Tag Dialogue

A dialogue system for Unreal Engine 5, driven by Gameplay Tags. Built for Blueprint.

Quick startGet it on Fab

1.0 · Unreal Engine 5.6

Tag Dialogue is a dialogue system for Unreal Engine 5. You write conversations in a node graph, and every conversation talks to the rest of your game through Gameplay Tags. An NPC can give a quest, a pickup can complete it, and a door can open when it hears about it. None of them need to know about each other.

Everything works from Blueprint. You don't need any C++.

Node graph editor

Lines, options, conditions, random and in-order picks, and action pills right on the wires.

Driven by Gameplay Tags

Dialogue talks to your game through tags: quests, doors and pickups react without hard references.

Quests built in

Ask, Reward (once) and Done lines. Tasks complete themselves when the right tags happen.

Barks

Ambient lines with no UI takeover: subtitles, speech bubbles above heads, or your own UI.

Ready-made UI

One click creates list, wheel and subtitle widgets. Or build your own from drop-in blocks.

Save anywhere

One-node save to slot, or capture the data into your own save system.

Live debugger

Watch the playing node glow in the graph while you play in the editor.

Write with AI

Import dialogues as JSON. A ready guide turns any AI chat into a dialogue writer.
