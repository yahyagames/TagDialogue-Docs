Troubleshooting

Problem Fix
Nothing shows on screen Run Create Templates, or set a Default Widget in Project Settings → Tag Dialogue UI. Check that Start Dialogue gets the player pawn as Instigator.
The dialogue shows twice You use a TDS Dialogue Layer or your own widget and Auto Show is still on. Turn it off.
Can't click options Turn on Manage Input Mode / Show Mouse Cursor for that style (Style Input).
Player keeps walking during dialogue Turn on Block Game Input (globally, or per style).
Barks don't show Check Show Bark Subtitles, the TDS Bark Widget's Max Distance, and that the NPC isn't in a conversation. Bark returns false on cooldown.
Bark shows twice You have both a bubble and a full-screen subtitle listening. Keep one, or turn off Listen To All Barks on the extra subtitle.
A spawned NPC forgets its task after loading Give it a fixed Save Id.
{Name} shows literally The variable isn't set (or is misspelled). Names are exact.
Reimport fails on an old asset Use Import Dialogue (JSON) once. After that Reimport remembers the file.
