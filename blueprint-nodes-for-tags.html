Blueprint nodes for tags

Usable from any Blueprint, with no setup:

Node What it does
Send Tag (+ Payload) Broadcasts once. The payload carries an Actor, a Number and a Text (e.g. who gave how many coins).
Add Tag / Remove Tag Change the tag state.
Has Tag (Exact Match) Reads the tag state.
Wait For Tag Async node: fires On Received once when the tag is sent or added. Options: Exact Match, Pass If Already Added, and Timeout (fires On Timeout).
Listen For Tag Async node: fires On Received every time, until Stop Listening or the Blueprint is destroyed. Good for quest logs.

On the Tag Subsystem (Get TDSTagSubsystem):

  • Get Tag State / Set Tag State
  • On Tag Sent / On Tag State Changed
  • Watch Task Completion / Get Task Progress
  • the text variable functions
  • the save functions
