Quick start

Goal: an NPC that talks when the player presses E. It takes about 5 minutes.

  1. Enable the plugin. Go to Edit → Plugins, search "Tag Dialogue", enable it and restart the editor.
  2. Create the UI. The first time the editor opens, a popup appears. Click Create Templates. - This creates ready-made dialogue widgets and sets them as the defaults. - You can do it later from Tools → Tag Dialogue → Create UI Templates, or by right-clicking a Content folder → Create Dialogue UI Templates.
  3. Create a dialogue. In the Content Browser: right-click → Tag Dialogue → Dialogue. Name it DA_Shopkeeper and open it.
  4. Write it. - A Start node and a first line ("Hello!") are already there. - Click the line and type its text in Details. - Right-click the graph → Add Line to add more, and wire the line's output into the next line's input. - Click Add option on a line to give the player choices.
  5. Add the component. Open your NPC Blueprint → Add Component → TDS Dialogue, then set Dialogue to DA_Shopkeeper.
  6. Start it. In the NPC (or player) Blueprint, when the player interacts, call Start Dialogue on the TDS Dialogue component. Pass the player pawn as Instigator.
  7. Play. - The dialogue widget appears. - Space, Enter or left click continues; Up/Down and 1–9 pick options. - When the conversation ends, input goes back to the game.

Until you set up a UI, Print To Screen (on by default on the component) prints every line and option to the screen.
