The TDS Dialogue component

Add it to anything that talks: NPCs, radios, notes, doors. It never decides when to talk; your Blueprint calls Start Dialogue.

Settings

Setting What it does
Dialogue The conversation asset.
UI Style Override Show this NPC differently from what the asset says (e.g. a radio uses UI.Dialogue.Subtitle).
Play Voice / Voice 2D / Voice Volume / Voice Attenuation Line audio. 2D is for narrators and radios; 3D comes from the actor.
Save Id The name of this NPC's memory in saves. Empty = the actor's name, which is fine for NPCs placed in a level. Set it for spawned NPCs.
Text Variables Per-NPC variables (see above).
Barks / Bark Cooldown / Bark Min Time See Barks.
Print To Screen Debug text on screen. Turn it off once you have a UI.

Functions

Function What it does
Start Dialogue (Instigator) Starts talking. Pass the player pawn so the right player's UI shows it.
Continue Next line (for lines without options).
Select Option (Index) Picks an option. Use the Index from the option view.
End Dialogue Stops now (e.g. the player walked away).
Reset Dialogue Forgets this NPC's task progress and closed options.
Close Option / Reopen Option / Is Option Closed Manual control over closed options.
Get Dialogue State Not Started, Task Running, Task Done (reward waiting) or Task Rewarded. Handy for a "!" or "?" above the NPC's head.
Is In Dialogue / Is Waiting For Tag State checks.

Events: On Dialogue Started, On Line Started (line + options), On Waiting For Tag, On Dialogue Ended, On Bark, On Bark Ended.

Async loading. Portraits and voices of the lines the player can reach next load in the background, so there are no hitches.
