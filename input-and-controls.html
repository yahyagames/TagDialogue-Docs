Input and controls

Project Settings → Tag Dialogue UI → Controls (works with any UI):

Setting Default
Confirm Keys (continue / choose highlighted) Space, Enter, Left Mouse, Gamepad A
Previous / Next Keys Up / Down, D-pad
Cancel Keys (walk out) Empty = the player can't leave mid-conversation
Number Keys Choose On (1–9)
Stick Points At Options On (wheel)
Block Game Input Off

Per style (Input → Style Input). Each UI style can treat input differently:

  • Manage Input Mode
  • Show Mouse Cursor
  • Block Game Input
  • Built In Controls

UI.Dialogue.Subtitle comes preset to no mouse and no lock, so the player keeps walking while a radio talks.

Turn Built In Controls off to drive the Session from your own Enhanced Input actions.
