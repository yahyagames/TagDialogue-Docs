TDS Tag State component

This component makes an actor follow the tag state, so the world matches the story with no save code.

Setting Example
When A tag query, e.g. Any Tags Match: Item.Key.Picked
Action Hide (hides it and turns off collision), Show (hidden until met), Destroy, or Events Only

It checks on Begin Play, every time tags change, and after loading a save. On State Changed (Met) fires each time, so you can do anything else in Blueprint (play an animation, open a gate). Add several to one actor for several reactions.

Examples:

  • A key pickup with Hide when Item.Key.Picked.
  • A gate blocker with Hide when Quest.FindKey.Done.
  • A reward chest with Show when Reward.Sword.

Prefer Hide over Destroy. A destroyed actor can't come back if the player loads an older save in the same session.
