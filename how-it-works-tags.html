How it works: tags

Tag Dialogue stores the game's story state as Gameplay Tags. It does this in two ways:

Send Tag (an event) Add Tag (memory)
What it means "This just happened" "This is now true"
Remembered? No. Listeners hear it once. Yes, until removed. Saved with the game.
Example Door.Main.Knock Quest.FindKey, Item.Key.Picked

All remembered tags together are called the tag state. Dialogue reads it for conditions, locked options and tasks. Your Blueprints read and write it with simple nodes: Send Tag, Add Tag, Remove Tag, Has Tag, Wait For Tag and Listen For Tag.

Parent tags count. Having Quest.FindKey.Done also counts as having Quest.FindKey unless you ask for an exact match. Listening to Quest hears every Quest.* tag.

Create your tags in Project Settings → Gameplay Tags as usual. Importing JSON adds missing tags for you.
