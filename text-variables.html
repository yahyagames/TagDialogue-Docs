Text variables

Write {Name} in any line, speaker, option or subtitle. It's replaced when shown.

"You have {Gold} gold, {PlayerName}."
Kind Where Saved?
Built in {PlayerName} is the Dialogue Hub's Player Display Name ("Me" by default). n/a
Global On the Tag Subsystem, for every NPC. Yes
Per NPC On the TDS Dialogue component (Text Variables map). These win over global ones. No

Blueprint functions (the same set on the Tag Subsystem and on the component):

Function What it does
Set Text Variable Adds or updates. Returns whether it changed, the old value, and whether it was new.
Add Text Variable Adds only. False if it already exists.
Update Text Variable Changes only. False if it doesn't exist. Returns the old value.
Remove Text Variable Removes. Returns the old value.
Get Text Variable Reads one.
Set Number Variable / Add To Number Variable / Get Number Variable Numbers, shown in the player's format (1,250). Add To takes negative amounts too.

On Text Variable Changed (Tag Subsystem) fires for every change, which is handy for a HUD gold counter. Unknown names stay as written, so a typo shows up on screen instead of silently disappearing.
